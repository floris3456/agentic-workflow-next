# Template maintenance backlog

This file records reusable-template concerns discovered during project work that await post-task human review. It is public-safe continuity/evidence, not authority to execute maintenance.

For each item use this compact shape:

```markdown
## <id> — <short title>

- Status: pending-human | rejected
- Observed need: <what was observed>
- Source evidence: <useful exact ref/path/evidence>
- Affected template surface: <config/instructions/layout/tooling/etc.>
- Human decision: <when known>
```

Do not add implementation plans, command logs, private reasoning, or routine project issues. When the human approves an item, create/use the canonical template-development task record and remove the item from this pending backlog once that transfer is durably represented.
