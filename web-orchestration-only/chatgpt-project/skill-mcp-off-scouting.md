# MCP-OFF public-web scouting

## Trigger

Use only when likely implementation areas are unknown and public-web orientation
is needed in MCP-OFF.

## Procedure

- Use the public GitHub tree, search, history, and exact files to identify likely
  components, symbols, interfaces, tests, contracts, and durable records.
- Keep the exact branch/ref visible and scout only enough to narrow the evidence
  surface. Switch from broad orientation to exact file/range evidence before a
  conclusion or review finding.
- Parallelize browser navigation only when it saves time; do not turn orientation
  into broad ritual for a quick lookup.
- State search/index limits and explicit unknowns. Public search is not a local
  symbol graph.
- Do not invoke, imply, or fabricate an OpenCode Scout, bridge request,
  delegation, or orchestration-state write. If implementation is required,
  return to the web-only workflow and prepare a bounded future task.
