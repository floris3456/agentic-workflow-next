# MCP-OFF repository scouting

## Trigger

Use when likely implementation areas are unknown and jCodeMunch is unavailable.

## Procedure

- Use public GitHub tree, search, navigation, and exact files.
- Scout only enough to identify likely components, symbols, tests, contracts, and records.
- Keep exact branch and ref visible.
- Do not pretend public search has the same symbol graph as jCodeMunch.
- Switch from broad orientation to exact file/history evidence before conclusions or review findings.
