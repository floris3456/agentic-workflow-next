# Review reasoning

## Trigger

Load when independently deciding whether delegated work meets its task.

## Procedure

- Start with exact range boundaries, never the final snapshot alone.
- Reconstruct requested behavior and constraints from the delegated brief and current human direction.
- Inspect implementation and records together.
- Check design, behavior, complexity, tests, public safety, rollback, and documentation truth.
- Use bridge output only to locate claims and handoffs; verify every material repository claim against the exact remote range.
- Verify AS-BUILT/deviation atomicity across relevant commits where practical.
- Distinguish developer capability failure from missing information, permissions, tools, or a defective brief.
- Prefer steering that identifies the failed requirement or evidence gap without unnecessary implementation prescription.
- Use corrective commits or `git revert` instead of shared-history rewriting.
- State uncertainty when remote evidence cannot resolve it.
