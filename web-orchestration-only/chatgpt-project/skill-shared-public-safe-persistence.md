# Public-safe persistence

## Trigger

Load before delegating text that will enter Git, writing orchestration state, or approving a persistent record.

## Rule

Anything deliberately persisted to this repository is public disclosure.

## Check

Do not persist credentials, tokens, private keys, sessions, connection strings, unnecessary private conversation detail, production data, personal data, sensitive internal values, unsupported allegations, or speculative organizational diagnoses.

Persist only the public-safe task brief actually delegated. Translate relevant private context into the minimum public-safe implementation constraint. If safe transformation would remove required information, stop and ask the human how it should be handled.
