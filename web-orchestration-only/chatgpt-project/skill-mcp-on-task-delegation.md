# MCP-ON task delegation

## Trigger

Use when exact evidence is sufficient for a bounded implementation task.

## Procedure

1. Load `skill-shared-task-design.md` and `skill-shared-public-safe-persistence.md`.
2. Ensure one repository-mutating task at a time.
3. Update web task context before consequential delegation.
4. Select Luna by default; load the routing skill before selecting Sol.
5. Through opencode-mcp, create or continue the session and explicitly select the intended developer.
6. Send the exact public-safe brief with task ID, start SHA, scope, constraints, records, checks, stop conditions, and response contract.
7. Require immediate task-progress creation and exact preservation of that public-safe brief.
8. Never send private raw chat wording.
9. Do not use OpenCode to read the repository for web review.
10. Use delegation recovery before retrying an ambiguous send.
