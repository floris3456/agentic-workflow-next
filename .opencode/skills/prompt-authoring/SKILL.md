# Prompt authoring

A research prompt must state:

- the exact decision/question;
- scope and exclusions;
- exact repository ref and smallest useful reading list;
- public-safe attachments and their limitations;
- required evidence labels and source quality;
- required output structure;
- whether implementation text is theoretical;
- contradiction and uncertainty handling; and
- the declared result target.

Do not copy preserved result sets wholesale into a prompt. Do not ask research to make human acceptance decisions. Keep prompt and result together in the study directory and validate the package before promotion.
