# Research workflow

Follow `research/WORKFLOW.md`.

- Create one package card per decision area.
- Keep each study's prompt, attachments, result, review, and synthesis co-located.
- Treat populated results and raw external evidence as immutable source evidence.
- Never place production data, private chat, credentials, or sensitive raw values in a public package.
- Start from package cards, indexes, manifests, and conclusions; do not ingest preserved results wholesale.
- Validate links, anchors, declared outputs, attachment metadata, and evidence hashes with repository validators.
- Research recommends; it does not approve policy, architecture, risk, production use, or gate acceptance.
- Promote a conclusion only through the correct durable home after human disposition.

Load `prompt-authoring` when writing or materially revising a research prompt.
