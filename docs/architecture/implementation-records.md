# Implementation records

## Task-record

For consequential work, maintain one accepted task-record in `docs/work/current/` using
`docs/work/templates/task-template.md`.

## Task-progress

Task-progress is optional and short. Use it only when continuity is useful for a larger run.

## AS-BUILT

Changed code requires concurrent AS-BUILT updates in the same commit to preserve directory-level completeness.

## Deviations

Formal deviations are durable, material difference reports when implemented reality diverges from the prior accepted normative expectation.

## Finalization

No mandatory handoff snapshot/finalization ceremony is required by this repository route model.
Generate or apply a change package only when the accepted task explicitly requires transfer, downstream application, or release packaging.
