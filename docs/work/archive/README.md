# Work archive

This directory retains immutable, public-safe task-progress snapshots for workflow benchmarking and historical analysis. Each archived task file is the exact substantively approved blob moved from `docs/work/current/` to the same basename during finalization, after useful durable facts are reconciled into their normative homes.

Archived task files are closed procedural history. They are non-authoritative, excluded from active-task discovery and scouting, and never substitute for AS-BUILT, deviations, design records, or current task-progress. Do not edit, replace, or reuse an archived task filename; record later corrections in the proper durable record or a newly delegated task. This README defines archive policy and is not itself a task snapshot.
