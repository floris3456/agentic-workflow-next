# Milestones and gates

A milestone explains a useful result in plain language. Its gate lists the evidence needed before dependent work starts. The human decides whether a gate is accepted; research, developer reports, and automated checks remain evidence only.

This template has no active milestone or gate. Create a project-specific record here only after defining its scope, accountable human, evidence, unresolved decisions, residual risk, and exact accepted SHA when applicable.

## Suggested gate record shape

1. Useful result and scope.
2. Work included and explicitly excluded.
3. Evidence and deterministic checks, with exact refs and hashes.
4. Known deviations and residual risk.
5. Human decision, date, and exact accepted SHA, or an explicit unresolved status.
6. Failure, recovery, rollback, and next safe action.
